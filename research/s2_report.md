## 2. Research gaps

1. **No MECE-partitioned supervision taxonomy exists.** Liu 2024, Tian 2024, Lee 2025 taxonomize *failure modes*; none classify supervision *interventions* themselves across orthogonal facets. Jiang's TOSEM survey is narrative prose, not partition-hygienic. SAICA-KG's ControlParadigm × TemporalPhase × AutonomyLevel framing appears absent.
2. **"Reinvention" is not yet a named failure class.** Liu 2025's "Code Copycat" studies *intra-generation* repetition — not the agent re-implementing code that already exists in the repo/dep graph. No paper in the 341-paper corpus labels this phenomenon as a supervision-addressable failure. This is the cleanest small-bore novelty slot.
3. **KG-as-MCP-artifact is unoccupied.** CKGFuzzer embeds a KG *inside* a tool; Farshidi's KG is a standalone recommender; MCP-Universe / MCPToolBench++ *evaluate* MCP tools without exposing a supervision ontology through MCP. Nobody serves a *supervision-taxonomy KG* as an MCP server for runtime consumption by coding agents.
4. **Empirical failure studies lack classification-theoretic structure.** Ehsani 2026 and Morabito-Wu 2025 produce flat failure lists with no partition guarantees. SAICA-KG's "honest MECE" (explicit about which facets are partitioned vs. multi-valued) fills a methodological gap.
5. **Graduated HITL is under-theorized.** The "HITL code generation" query returned only 13 results, almost none treating autonomy-level as a first-class axis orthogonal to control paradigm and temporal phase.

## 3. Novelty assessment

**Strongest form of the claim:** SAICA-KG's defensible novelty is the *combination* of (a) explicitly partitioned faceted classification of supervision interventions, (b) machine-readable delivery of that classification as a KG exposed over MCP so that coding agents query it at runtime, and (c) "reinvention" as a named, placed failure class alongside fabrication and obsolescence. Each alone is modest; together they form a cohesive methodological + systems contribution.

**Weakest attack surface:** A reviewer will argue "honest MECE faceting" is rebadged facet-analysis from library/information science (Ranganathan, OntoClean). Without an empirical demonstration that existing taxonomies (Liu, Tian, Lee) *violate* MECE in ways that cause concrete downstream problems — ideally by re-classifying their categories and showing overlap or gaps — the claim reads as terminological rather than substantive. A small re-classification study would neutralize this attack.

**Most defensible contribution:** **KG-as-MCP-artifact**, because it is verifiable (the artifact runs), non-obvious (absent from the corpus), and bridges two literatures (supervision taxonomy + MCP tooling). **Reinvention-as-failure-class** is second-most defensible if paired with an empirical prevalence study on SWE-bench traces. **Honest-MECE faceting** is weakest stand-alone and should be framed as methodology in service of the other two, not as the lead claim.
